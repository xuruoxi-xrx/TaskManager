# TaskManager — Python 待办事项管理系统

## 项目简介

TaskManager 是一个使用 Python 开发的命令行待办事项管理系统，支持任务添加、查看、完成和删除，并通过 JSON 文件实现数据持久化。

本项目采用模块化设计，将用户交互、业务逻辑和数据存储分离，适合 Python 基础学习与实践。

## 主要功能

- 添加任务：自动生成任务编号，防止添加空任务
- 查看任务：显示任务编号、名称和完成状态
- 完成任务：根据编号更新任务完成状态
- 删除任务：根据编号删除任务
- 异常处理：处理非法编号、无效菜单选项等输入
- 数据持久化：通过 JSON 文件保存任务

## 技术栈

- Python 3
- JSON
- pathlib
- 命令行交互（CLI）

## 运行方式

确保已安装 Python 3，在项目目录下运行：

```bash
python main.py
```

按照菜单提示选择对应功能即可。

## 项目收获

通过本项目，实践了 Python 函数、列表、字典、循环、条件判断、模块导入、异常处理、文件操作和 JSON 数据持久化等知识，并初步掌握了模块化项目的组织方式。
