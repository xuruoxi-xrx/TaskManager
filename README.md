# TaskManager — Python 待办事项管理系统

## 项目简介

TaskManager 是一个基于 Python 开发的命令行待办事项管理系统（CLI），目前已更新至 2.0 版本。

项目支持任务的添加、查看、完成、删除、关键词搜索、状态筛选及任务统计，并提供任务优先级、截止日期和优先级排序功能。

系统使用 JSON 文件实现数据持久化，采用模块化设计，将用户交互、任务业务逻辑和数据存储分离。

## 主要功能

- **添加任务**：输入任务名称、优先级和截止日期，自动生成任务编号。
- **查看任务**：显示任务编号、名称、完成状态、优先级和截止日期，并按优先级排序。
- **完成任务**：根据任务编号将任务标记为已完成。
- **删除任务**：根据任务编号删除指定任务。
- **搜索任务**：根据关键词搜索任务名称，支持忽略英文大小写。
- **筛选任务**：按已完成或未完成状态筛选任务。
- **任务统计**：统计总任务数、已完成数、未完成数和任务完成率。
- **输入验证**：检查空任务名称、无效优先级、非法日期和错误任务编号。
- **数据持久化**：通过 JSON 文件保存任务，重新启动程序后仍可读取。
- **异常处理**：处理非法输入及 JSON 解析错误，降低意外覆盖数据的风险。

## 技术栈

## 技术栈

- Python 3
- JSON：任务数据持久化
- pathlib：文件路径管理
- datetime：截止日期格式验证
- CLI：命令行交互

## 运行方式

确保已安装 Python 3，在项目目录下运行：

```bash
python main.py
```

按照菜单提示选择对应功能即可。
